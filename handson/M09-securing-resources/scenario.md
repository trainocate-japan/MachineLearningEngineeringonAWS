# モジュール 9: AWS ML リソースの保護 - ハンズオンシナリオ

## シナリオ概要

ML システムは機密性の高いデータを扱うため、適切なアクセス制御が不可欠です。あなたは AnyCompany の ML エンジニアとして、最小権限の IAM ポリシーを「表示するだけ」で終わらせず、IAM Policy Simulator で実際に許可/拒否を評価して検証します。さらに、デプロイ済みの SageMaker 実行ロールの実効権限も確認します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **最小権限ポリシーを検証する**: 許可すべき操作が Allow、許可すべきでない操作が Deny になることを実際に評価する
2. **実ロールの権限を確認する**: デプロイ済み IAM ロールの実効権限をシミュレートする
3. **ネットワーク分離と暗号化を理解する**: VPC / セキュリティグループ / KMS の考え方を整理する

## 使用する AWS サービス / ツール

- AWS IAM Policy Simulator（simulate-custom-policy / simulate-principal-policy）
- AWS IAM（ポリシー・ロール）

## 所要時間

約 30 分

## 前提条件

- Python パッケージ: `boto3`
- `$SAGEMAKER_ROLE_ARN` が設定済み（実ロール検証を行う場合）
- IAM のシミュレーション権限（管理者アクセスがあれば十分）
