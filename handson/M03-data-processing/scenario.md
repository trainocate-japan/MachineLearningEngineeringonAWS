# モジュール 3: データ処理と探索的データ分析 - ハンズオンシナリオ

## シナリオ概要

あなたは AnyCompany の ML エンジニアです。マーケティング部門から「顧客の人口統計データから、年収が閾値（50,000 ドル）を超えるかどうかを予測したい」という依頼を受けました。パーソナライズされたマーケティングコンテンツの配信先を最適化するためです。

モデルをトレーニングする前に、まずは手元のデータを理解する必要があります。このハンズオンでは、生のデータセット（品質問題を含む）を pandas で探索し、可視化して、データ品質の問題を特定します。生成した図は署名付き URL でブラウザから確認できます。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **データ形式とデータ型を理解する**: 行ベース（CSV）と列ベース（Parquet）の違い、構造化・半構造化・非構造化データを区別する
2. **探索的データ分析（EDA）を実施する**: pandas で統計量を計算し、欠損・重複・外れ値を特定する
3. **データを可視化する**: 分布（ヒストグラム・ボックスプロット）、関係（散布図・ヒートマップ）、構成（棒グラフ）を目的に応じて使い分ける
4. **データ品質問題を特定する**: 欠損値、重複行、外れ値、書式ゆれを発見する
5. **生成した図をブラウザで確認する**: 署名付き URL で可視化結果を共有する

## データセット

共通データセット「成人の収入予測」（`common/generate_dataset.py` で生成）を使用します。

| 列名 | 型 | 説明 |
|------|-----|------|
| `age` | 数値 | 年齢 |
| `workclass` | カテゴリ | 雇用形態 |
| `education` | カテゴリ | 最終学歴 |
| `education_num` | 数値 | 教育年数 |
| `occupation` | カテゴリ | 職業 |
| `hours_per_week` | 数値 | 週あたり労働時間 |
| `state` | カテゴリ | 居住州 |
| `income_text` / `income_usd` | 文字列/数値 | 年収 |
| `income_high` | 0/1 | **ターゲット**: 収入が閾値を超えるか |

生データ `raw_income.csv` には、意図的に以下の品質問題が含まれています：
- 欠損値（`age`, `state`）
- 重複行
- 外れ値（`age` が 120 以上）
- 書式ゆれ（`income_text` が `"73K"`, `"$93605"`, `"117,451"` など混在）

- pandas / matplotlib（ローカル EDA・可視化）
