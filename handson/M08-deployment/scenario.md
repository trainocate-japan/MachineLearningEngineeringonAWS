# モジュール 8: モデルデプロイ戦略 - ハンズオンシナリオ

## シナリオ概要

トレーニングと評価が終わったモデルを、本番環境に配置して推論できるようにします。あなたは AnyCompany の ML エンジニアとして、ユースケースに応じた推論オプション（リアルタイム / バッチ）を選び、安全なデプロイ戦略（ブルー/グリーン・トラフィックシフト）を実装します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **デプロイターゲットの選択**: SageMaker エンドポイント / EKS / ECS / Lambda の違いを理解する
2. **推論オプションの選択**: リアルタイム / サーバーレス / 非同期 / バッチ変換をユースケースで使い分ける
3. **リアルタイムエンドポイント**: モデルをデプロイして低レイテンシ推論を実行する
4. **バッチ変換**: 大量データに対してオフライン推論を実行する
5. **トラフィックシフト**: ブルー/グリーンデプロイ（Linear / Canary / All-at-once）で安全に更新する

## データセット

M04 で生成した `features_income.csv` を使用し、モデルをトレーニングしてからデプロイします（ハンズオンを自己完結させるため）。既存の M06/M07 のモデルを使っても構いません。

## 使用する AWS サービス / ツール

- Amazon SageMaker リアルタイムエンドポイント
- Amazon SageMaker バッチ変換
- SageMaker デプロイガードレール（トラフィックシフト・自動ロールバック）
- Amazon SageMaker 組み込み XGBoost
