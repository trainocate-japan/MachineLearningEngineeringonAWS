# モジュール 11: モデルモニタリングとドリフト検出 - ハンズオンシナリオ

## シナリオ概要

モデルを本番にデプロイしたら終わり、ではありません。時間の経過とともにデータ分布が変化し、モデルの精度は劣化します。あなたは AnyCompany の ML エンジニアとして、収入予測モデルのエンドポイントにデータキャプチャを設定し、Amazon SageMaker Model Monitor でベースラインからのドリフトを検出する仕組みを構築します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **ドリフトの種類を理解する**: データ品質ドリフト / モデル品質ドリフト / バイアスドリフト / Feature Attribution ドリフト
2. **データキャプチャ**: エンドポイントの推論リクエスト/レスポンスを S3 にキャプチャする
3. **ベースライン作成**: トレーニングデータから統計量と制約（statistics.json / constraints.json）を生成する
4. **モニタリングスケジュール**: 定期的にデータ品質を検査するジョブをスケジュールする
5. **ドリフトのシミュレーションと検出**: 分布を意図的に変化させ、ベースラインからの逸脱を観察する

## データセット

M03〜M10 と同じ「成人の収入予測」データセットを使用します。ドリフトのシミュレーションでは、`age` や `hours_per_week` の分布を意図的にシフトさせます。

## 使用する AWS サービス / ツール

- Amazon SageMaker Model Monitor（DefaultModelMonitor）
- Amazon SageMaker リアルタイムエンドポイント（データキャプチャ）
- Amazon CloudWatch（メトリクス・アラーム）
- Amazon S3（キャプチャデータ・ベースライン）

## 所要時間

約 45 分
