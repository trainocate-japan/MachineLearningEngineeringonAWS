# モジュール 4: データ変換と特徴量エンジニアリング - ハンズオンシナリオ

## シナリオ概要

M03 で特定したデータ品質問題を実際に修正し、モデルがトレーニングできる形にデータを変換します。あなたは AnyCompany の ML エンジニアとして、収入予測モデル向けの特徴量を設計します。

ローカルの pandas / scikit-learn で変換ロジックを確認した後、同じ処理を Amazon SageMaker Processing ジョブとしてスケール実行する方法を学びます。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **データクリーニング**: 欠損値の補完、重複排除、外れ値の処理、書式ゆれの修正を実装する
2. **カテゴリカルエンコーディング**: ラベルエンコーディング・序数エンコーディング・ワンホットエンコーディングを使い分ける
3. **数値特徴量エンジニアリング**: 正規化・標準化・ビニング・対数変換を適用する
4. **特徴量選択**: 不要な特徴量の削除、分割・結合、PCA による次元削減を実施する
5. **SageMaker Processing**: 変換処理をマネージドジョブとしてスケール実行する

## データセット

M03 と同じ「成人の収入予測」データセット（`common/generate_dataset.py`）を使用します。
生データ `raw_income.csv` を入力として、クリーン＆エンコード済みの特徴量を出力します。

## 使用する AWS サービス / ツール

- Amazon SageMaker Processing（マネージドデータ処理ジョブ）
- Amazon S3（入出力）
- scikit-learn（StandardScaler / OneHotEncoder / PCA）
- pandas

約 45 分
