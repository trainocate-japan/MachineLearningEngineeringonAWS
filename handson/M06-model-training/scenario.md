# モジュール 6: ML モデルのトレーニング - ハンズオンシナリオ

## シナリオ概要

採用したアルゴリズム（XGBoost）で、収入予測モデルを本格的にトレーニングします。あなたは AnyCompany の ML エンジニアとして、まずローカルで XGBoost を学習させてモデルの挙動（損失・学習曲線・特徴量重要度）を理解し、その後同じ学習を Amazon SageMaker トレーニングジョブとしてスケール実行します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **モデルの構成要素を理解する**: アルゴリズム + 重み（パラメータ）、損失関数、最適化、ハイパーパラメータ
2. **ローカルトレーニング**: XGBoost で二項分類モデルを学習し、学習曲線を観察する
3. **過学習・過小適合を観察する**: トレーニング損失と検証損失の乖離を確認する
4. **SageMaker トレーニングジョブ**: マネージドな学習を実行し、モデルアーティファクトを S3 に保存する

## データセット

M04 で生成した `features_income.csv`（ターゲット `income_high`）を使用します。

## 使用する AWS サービス / ツール

- Amazon SageMaker Training（マネージドトレーニングジョブ）
- Amazon SageMaker 組み込み XGBoost
- Amazon S3（データ・モデルアーティファクト）
- xgboost（ローカル）
